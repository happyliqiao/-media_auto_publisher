# 2026-10-28

## 排查「程序没有自动运行」

用户反馈自动发布没跑。查出三个叠加故障，任一都足以让整条链路停摆：

1. **计划任务指向不存在的路径**
   任务 `AI_Content_AutoPublisher` 的执行命令是
   `E:\media_auto_publisher\start_daemon.ps1`，项目实际在
   `E:\liqiaobac\-media_auto_publisher`。任务今天 10:02 确实被登录触发，
   但找不到脚本直接失败（LastTaskResult 非 0），且从未生成过 `logs/daemon.out.log`。

2. **`install_startup_task.ps1` 语法错误，从未成功执行**
   第 7 行 `-Argument "... -File \`"$ProjectDir\start_daemon.ps1\`"` 少一个结尾引号，
   整个脚本无法解析（"字符串缺少终止符"）。所以「注册开机自启」这一步一直是空转，
   现有任务其实是更早的旧路径残留。

3. **`start_daemon.ps1` 启动环节崩溃**
   本机进程环境里同时存在 `http_proxy` / `HTTP_PROXY`、`https_proxy` / `HTTPS_PROXY`
   （大小写各一份，值都是 `http://127.0.0.1:53611`）。这会让 PowerShell 的
   环境变量提供程序抛「已添加了具有相同键的项」，连 `Get-ChildItem Env:` 都失败，
   `Start-Process` 直接 ArgumentException —— 脚本在启动 python 前就退出了。

## 修复

- `install_startup_task.ps1` 重写：用字符串拼接构造参数，消除嵌套转义引号；
  新增每 30 分钟重复的看门狗触发器（配合 start_daemon 的幂等启动）。
- `start_daemon.ps1` 重写：改用 `[System.Diagnostics.Process]::Start` 启动子进程，
  绕开 `Start-Process` 的重复环境变量崩溃；解释器改为固定候选列表（不再递归扫描，
  实测扫描 `~/.workbuddy-ai/binaries/python/versions` 返回空）；
  只在代理指向回环地址时清理，避免误删正常代理。
- `main.py`：daemon 自己写 `logs/daemon.log`（不再依赖外部重定向，带 5MB 轮转）；
  新增 `storage/daemon.lock` 单实例锁（Windows 用 OpenProcess+GetExitCodeProcess 判活，
  不能用 `os.kill(pid,0)`，那在 Windows 上会真把进程杀掉）；
  未过审不再触发浏览器发布。
- `content_generator.py`：新增 DeepSeek/OpenAI 兼容接口，用标准库 urllib 实现
  （系统 Python 没装 `openai` 包，也不想去污染它），生成时把近期标题传给模型避免撞题；
  失败自动回退模板。

## 验证

- `Start-ScheduledTask` 触发后：`LastTaskResult=0`，`logs/launcher.log` 记录
  `started pid=14120`，`logs/daemon.log` 有 `daemon_started=true`，进程存活，
  锁文件写入，`next_run_at=2026-10-28T21:54`。
- 用工具直接起的 daemon 会被沙箱回收（子进程随会话结束），**必须靠计划任务启动**。

## 新发现：内容生成走不通

- DeepSeek 密钥有效（鉴权通过），但账户**余额不足**：
  `HTTP 402 Insufficient Balance`。只能回退模板。
- 模板只有 5 套固定文本，只有场景词会变 → 第 6 篇起必然与历史文章高度重复，
  被查重拦下（实测相似度 0.97 ≥ 阈值 0.65），稿件进 `_rejected/`，不发布。
- 结论：**模板模式无法长期支撑自动发布**，必须走 LLM 生成。待用户决定充值或换 key。
