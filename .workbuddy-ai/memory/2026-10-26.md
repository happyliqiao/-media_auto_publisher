## 主题重构：普通人如何正确使用 AI 工具

按用户要求，把项目内容主题从「OpenAI Codex / Claude Code 免费额度推广」改为「普通人如何正确、合适地使用 AI 工具」，核心功能（定时生成 + 按约定时间发布）保持不变。

改动清单：
- `config.example.json`：重写 topic / required_terms / blocked_terms / disclaimer；新增 `schedule`（stages、publish_hours）与 `platforms.toutiao.options`；`openai_model` 由 gpt-5.5 改为 gpt-4.1。
- `content_generator.py`：重写为 5 套轮换模板（正确姿势 / 常见误解 / 一天里的用法 / 提问公式 / 能力边界），按「日期+小时」做随机种子，跨小时自动换模板与场景。
- `reviewer.py`：删除失效的「免费+以官方」硬编码检查，改为校验 `topic.required_disclaimer`；新增与近期文章的字符二元组 Jaccard 重复度检测（阈值 `review.max_similarity`，默认 0.65）。
- `scheduler.py`：改为读取 `config.schedule`；新增 `publish_hours` 时段约束（默认 7-23 点，避免凌晨发稿）。
- `storage.py`：新增 `recent_texts()` 供查重；meta json 增加 `created_at` / `title`。
- `publishers.py`：队列文件增加 `consumed_at`；非 dry-run 时也写队列供浏览器自动化消费。
- `main.py`：串联查重；新增 `plan` 子命令预览当天排期；daemon 单次失败不再中断。
- `toutiao_browser.py` / `run_toutiao_full_publish.py`：封面/广告/位置/声明/定时偏移全部改为读配置（原硬编码「武汉」「个人观点，仅供参考」）；`latest_toutiao_queue` 跳过已发布/已消费的队列。
- 新增 `requirements.txt`，重写 `README.md`。
