- 发布接口成功时 `data` 里回显完整正文（`data.content`）。

### ⚠️ 事故：同一篇发了 3 次
- 09:37 / 09:38 / 09:40 各发了一次。原因是**调试用的 probe 脚本也走了完整发布流程**（`probe_submit.py`/`probe_validate.py`/`probe_network.py`），而当时成功判据只看页面文案，判不出来就又发一次。
- 教训：**任何探针都不能点「确认发布」**；调试时用 `--submit` 之外的路径或只 dry-run。
- 已删除全部 probe 脚本。

### 修复
- 新增**发布指纹库** `storage/published_toutiao.json`：指纹 = sha1(标题 + 正文前 200 字)[:16]。发布前查重，命中则跳过；结果不确定（`submit_unconfirmed`）也记录指纹防止重试。删掉指纹即可恢复。
- 页面元素改为**批量枚举**（一次 `page.evaluate` 取全部 button / radio / checkbox），避免逐个 evaluate 触发重渲染导致 `PlaywrightTimeoutError` 误判成超时。
- `page.set_default_timeout(60000)`，截图单独给 20s 超时。
- `run_toutiao_full_publish.py` 收敛为 `toutiao_browser` 的薄封装，消除双份 DOM 实现。
- Markdown → 纯文本时**去掉空行**（否则 `insert_text` 会产生大量 `<p><br></p>` 空段落，页面段落间距过大）。
